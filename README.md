# Semana Cultural Zaragoza 2025

Proyecto realizado para la práctica de Diseño Web + GitHub + Cliente de correo.

## Descripción del proyecto
Sitio web informativo sobre la Semana Cultural de Zaragoza 2025.  
Incluye navbar, hero, dos secciones con grid y footer, siguiendo los requisitos de Bootstrap 5.

## Secciones y columnas usadas
- Navbar – Bootstrap 5
- Hero – Imagen + overlay
- Sección 1 (Información)  
  - Grid con `row`  
  - 2 columnas (`col-md-6` + `col-md-6`)
- Sección 2 (Actividades)  
  - Grid con `row`  
  - 3 columnas (`col-md-4`)  
  - Uso de cards de Bootstrap
- Footer

## Componentes Bootstrap usados
- Navbar  
- Cards  
- Grid system  
- List group  
- Buttons  

## Commits realizados
1. Estructura base del proyecto.
2. Añadido Hero y estilos CSS.
3. Secciones con grid y cards.
4. Footer y ajustes finales.
5. README y carpeta CAPTURAS.

## Dificultad principal
La mayor dificultad fue ajustar el diseño responsive del hero y las cards.  
Se solucionó usando clases de Bootstrap como `d-flex`, `align-items-center` y `col-md-*`.
